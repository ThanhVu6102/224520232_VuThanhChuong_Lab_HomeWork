# Project rules — Lab 3

- React 19, Vite, ES modules, function components, createRoot và StrictMode.
- HTML semantic, CSS Module, bàn phím và focus rõ ràng, responsive 375–1440px.
- Không dùng legacy APIs, index key, dangerouslySetInnerHTML hoặc đồng bộ derived state bằng effect.
- Input có label và useId. State cập nhật bất biến.
- Timer/listener/audio/async phải cleanup khi unmount. Không commit node_modules, dist, secret.
- Tách contract, logic, UI, verification thành các bước WBS. Chỉ ghi nhận kiểm thử thực tế, không bịa chứng cứ DevTools/Lighthouse.
